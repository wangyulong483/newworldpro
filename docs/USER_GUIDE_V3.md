# newworld 新世界用户指南（V3 俯视地图 · 世界盒子风格）

> 对应代码：`newworld/app_map.py`（界面）+ `map_engine.py`（地形）+
> `swarm.py`（群伙）+ `catastrophes.py`（灾害）。
> 本文只描述**已实现并实测验证**的行为；已知限制见文末 §7。
> 旧世界（侧视像素小人）的操作指南是另一份：`docs/USER_GUIDE.md`。

---

## 1. 启动

```powershell
cd newworldpro

# 新世界（默认）：俯视地图 + 千人群伙 + 上帝之手
python -m newworld

# 指定种子（地形与初始人口不同）
python -m newworld --seed 7

# 指定地图尺寸（cell 数；默认 512×320）
python -m newworld --size 256x160

# 启动后自动截图并退出（验证渲染）
python -m newworld --screenshot .tmp\map.png --autoclose-ms 3500
```

桌面快捷方式「newworld 像素世界」（`start_world.bat`）默认进入本世界。

**回到旧世界**：加 `--classic`（侧视像素小人 + 8 人文明，V1/V2 全部机制）。

## 2. 你会看到什么

一张 512×320 cell 的岛屿地图（每 cell 渲染为 3×3 像素色块）：

| 颜色 | 地形 | 说明 |
|---|---|---|
| 深蓝 | 深海 | 不可居住 |
| 浅蓝 | 浅海 | 个体会溺亡 |
| 米黄 | 沙滩 | 少量食物 |
| 绿色（亮） | 草地 | 主要食物来源，越亮食物越多 |
| 深绿 | 森林 | 食物较少但会向草地蔓延 |
| 灰褐 | 山地 | 可行走不可食 |
| 白色 | 雪原 | 高海拔 |

地图上散布的**彩色小点**就是居民：颜色表示饱足度——
暗红（快饿死）→ 橙 → 黄 → 亮青（吃饱）。几千个小点在地图上
觅食、迁徙、聚居，就是这个世界的主画面。

初始人口 220，出生在有食物的陆地上，会自然繁衍到
**动态承载力**（实测约 5000，随地图肥沃度变化）。

## 3. 上帝之手（核心玩法）

顶部工具栏五个按钮，选中后**点击地图**施放：

| 按钮 | 效果 | 提示 |
|---|---|---|
| 观察 | 只查看统计 | 默认模式 |
| ☄ 陨石 | 撞击坑：中心焦土、范围内个体死亡、边缘点燃森林 | 人口稠密处效果最震撼 |
| ⚡ 闪电 | 点燃一处森林/草地 | 火会蔓延；烧完变草地、食物清零后慢慢恢复 |
| 🌊 洪水 | 圆形区域低地淹为浅水 | 个体会溺亡；山地不易被淹 |
| ✚ 治愈 | 灭火 + 食物瞬间回满 + 圆内个体饥饿回满 | 灾后重建神器 |

注意：灾害作用于**真实世界状态**（地形网格/食物/个体生死），
不是动画效果——施放后人口统计与食物总量立刻反映。

## 5. 信息面板（右侧）

* **人口**：当前数量 / 承载力估计 / 累计出生死亡 / 死因四分类
  （饿死/老死/溺亡/烧亡）；
* **地图**：各地形 cell 数、食物总量；
* **灾害史**：最近 8 次施放的种类、位置与杀伤。

底部状态栏：人口、出生、死亡、食物、燃烧格数、速度、FPS、当前工具。

## 6. 人口动态规律（帮助理解你在看的）

* 个体**饥饿递减**，站在食物格上进食；饱足 ≥0.95 懒得动；
* 饿了向**食物浓度更高的方向**移动（带随机性，会扩散）；
* 繁衍需要：成年（12s）+ 饱足（≥0.55）+ 所在格有食物（≥0.12）
  + 冷却结束（14s）+ 概率（0.1/s）；
* 人口超过承载力时**全体暂停繁衍**（软约束）；
* 死亡：饥饿归零 / 老年（90s 后危险率 0.05/s）/ 落水 / 站火里。

所以典型剧情是：开局人口爆发 → 把聚集地吃穷 → 向外扩散觅食 →
在承载力附近震荡。扔颗陨石或闪电，看人口怎么跌、怎么恢复。

## 7. 已知限制（如实）

1. **整图可视，暂无缩放/平移**（滚轮当前是调速）；
2. 超大人口（>6000）时散点隔点渲染；8000 人全管线约 41 FPS
   （仿真本身 1.9ms/帧，瓶颈在绘制）；
3. 无昼夜视觉（daylight 只影响食物再生系数）；
4. 部落/战争/瘟疫未实现（二期）；
5. 程序化 UI 自检（`--ui-test`）尚未覆盖新世界，当前用截图+像素统计验证。

## 8. 命令行参数一览（新世界相关）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--seed N` | 0 | 地形与人口种子 |
| `--size WxH` | 512x320 | 地图 cell 数 |
| `--cell N` | 3 | 每 cell 渲染像素 |
| `--screenshot PATH` | — | 启动后截图并退出 |
| `--autoclose-ms N` | — | 自动关闭（配合截图） |
| `--classic` | 关 | 进旧世界（见 `USER_GUIDE.md`） |
