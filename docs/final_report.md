## 1. 执行摘要

任务：在**最多创建 8 个 Agent** 的硬约束下，保留原有神经网络与世界模拟器，
补上目标规划、持久记忆、技术创新、知识传承、代际演化与社会机制，让文明在长期模拟中
出现真实的积累、发展、分化、衰退与延续。

完成情况（P0–P4 全部落地，均有测试与实测证据）：

| 阶段 | 结果 | 关键证据 |
| --- | --- | --- |
| P0 审计/日志/基线 | ✅ | 审计报告 + 3 个探针；发现原系统 **537.55s 全族饥饿灭绝**、主循环奖励恒 0、教师接管 58% 决策、死亡即删除、累计创建可破 8 |
| P1 目标规划 | ✅ | `goals.py`；group B（仅加规划）灭绝时间 419.6s→597.9s（+42%），最长重复动作 4378→54.7 步 |
| P2 知识/技术 | ✅ | `knowledge.py` + 数据驱动技术（7 条）+ 模拟器唯一验证；group C/D 验证 4.67±0.47 项技术、4 个设施、依赖图深度 1 |
| P3 记忆/传承/人口上限 | ✅ | 历史注册表 + 死亡档案 + 出生继承 + 邻近教学；累计创建严格 =8（跨组、跨 seed） |
| P4 社会/设施/扰动/崩溃 | ✅ | 粮仓等设施真实供能、合作指数 0.867±0.094（C 组为 0）、三种环境扰动按 seed 触发、collapse 五态机与灭绝原因 |

**核心结论**：原始系统不是"停滞"，而是**自我灭绝**（教师接管后不再进食，8 人全部饿死）。
修复机制 + 增加规划与知识后，同一 8 人世界可以**自发发现并验证 4–5 项技术、建造 4 个公共设施、
围绕粮仓定居、把知识传给下一代**，最终因 8 人硬上限在老年期自然全灭
（1031.3±1.1s）。**文明延续体现为知识档案与代际继承，而不是人口增长**——这是硬约束的直接后果。

## 3. 审计关键发现（决定改造方案的事实）

1. **没有强化学习算法**：主路径是监督式行为克隆（MLP 24→64→32→58，5594 参数），
   无奖励、无策略梯度、无价值函数。`env.py` 的 RL 包装器（8 维/3 动作/4 奖励）
   从未被主程序使用。→ 因此**没有引入** PPO/DQN。
2. **重复动作的结构性原因**：社区建成后手写教师 `SocialLife` 的求偶分支对成年个体
   恒成立且从不返回 `None`，神经网络被静音；个体不再进食 → 全员能量单调下降 →
   **t=537.55s 全族饥饿灭绝**（8/8 starved）。`social` 状态占 82.7% 个体-步，
   最长连续同状态 2227 步。
3. **世界食物链本身是坏的**：480×300 与 800×500 世界生成 **0 个浆果丛**（食物为 0）；
   即使生成，浆果被采后也**永远不会再生**（生长条件要求 `leaf`，而采集把原子清空）。
4. **死亡即删除**：`world.remove_agent` + `Population.sync` 的 `del minds[id]`
   丢掉身体、库存、知识、权重对象；无 `died_at`、无历史注册表。
5. **上限口径错误**：`MAX_POPULATION=8` 判的是存活数。受控复现
   （`experiments/probe_cap_path.py`）证明：8 人 → 1 人老死 → 再生育 →
   **创建第 9 个个体**。
6. **无目标/计划/知识/记忆/技术依赖图**；技术层只有一条硬编码配方（2 木+1 石→斧），
   公共设施是屏幕中央一个永久有效的社区站点。

## 4. 机制改造（按阶段）

### P0 修复（机制缺陷，先修再做功能）

| 修复 | 文件 | 效果 |
| --- | --- | --- |
| 世界保证最少浆果丛 | `pixelworld._ensure_food_supply` | 每个尺寸的世界都有食物网（≥2 丛） |
| 浆果可再生 | `ecology._grow` | 采空后可在原槽位重新生长 |
| 教师生存优先 | `social.SocialLife.decide` | 能量<35/水分<30 时返回 `None`，不再饿死全员 |
| 受约束创建 | `world.create_agent` + `AgentRegistry` | 累计创建 ≤8，第 9 次返回 None 并记录拒绝 |
| 禁止隐式复活 | `World.agent` 抛 `NoAgentsError` | 灭绝后不会因属性访问 spawn 新个体 |
| 指标采集 | `telemetry.py`（19 指标） | 动作分布/重复/目标/技术/留存/合作/灭绝 |
| 测试环境垫片 | `tests/_env_compat.py` | 消除沙箱下 6 个 tempdir 假错误 |

### P1 目标规划（`goals.py`）

- `GoalManager.update()` 每帧：结算目标 → 生成目标（需求/机会/设施/知识候选）→
  选择最高优先级 → 推进计划 → 返回 `Decision`；无把握返回 `None` 交回教师/神经。
- 计划为**结构化步骤**（`verb + args`），执行器只调用 `technology` 公开接口。
- 反卡死：45 世界秒/240 步无进展 → replan；同一计划 3 次 replan → abandon + 冷却；
  步骤 attempts 超限 → 失败。
- 无知识库时退化为内置 `gather→craft→build` 链（P1 可独立验收）。
- **Lead 集成补丁**：实验计划先采集缺失材料；候选技术按尝试次数轮转，避免卡在难题。

### P2 知识与技术（`knowledge.py` + `technology.py`）

- 7 条技术作为**世界规则**：石斧、纤维绳、背篓、篝火、水井、小屋、粮仓。
- `hypothesis → verified → invalidated`；只有 verified 可用于 craft/build；
  每次验证走 `Technology.simulate_recipe`（真实扣材料、产产物、按 difficulty 可失败）。
- 前置条件失败（缺材料/缺工具）**不计为技术缺陷**（Lead 补丁，避免误判失效）。
- 技术真实效果：采集×2、负重+4、夜间/休息恢复、取水半径、食物储存。
- 依赖图：`edges/verified_edges/depth`；技术发现者/时间/使用次数可追踪。

### P3 记忆、传承与人口上限（`memory.py` + `civilization.py` + `population.py`）

- `AgentRegistry`：历史累计创建只增不减，死亡档案含库存/知识/技能/记忆/亲子关系。
- 死亡流程：`on_death` 先归档 → 标记死亡 → 移除活体 → 销毁脑对象（不可再行动）。
- 出生流程：唯一受约束路径 `Population.create_agent`；子代继承父母已验证知识 + 程序记忆。
- 社会学习：170px 内验证知识按概率传播（教师/学生事件可追踪）。
- 观测扩维 24→40（8 记忆 + 4 目标 + 4 文明），旧 checkpoint 零初始化迁移、输出逐比特一致。

### P4 社会、设施、扰动、崩溃（`civilization.py` + `simulation.py`）

- 公共设施：建造后按半径提供真实效果，随时间损耗，维护消耗材料，失效影响 collapse 判定。
- 基础设施反射：能量低时前往活跃粮仓/篝火/小屋休息（村庄形成的机制原因）。
- 食物分享合作：饱食者给 60px 内低能量者转移能量（真实资源流，计入合作指标）。
- 环境扰动：每次运行按 seed 在 60–150s 起依次经历干旱/风暴/资源枯竭（摧毁整棵浆果丛、
  整棵树/岩体、土壤湿度骤降），事件写入 JSONL。
- `collapse_state` 五态机 + 灭绝时间/原因；`Population` 在存活为 0 时强制判定灭绝。

## 5. 实验结果（真实数据）

### 5.1 消融配置（固定预算）

`800×500`、`dt=0.05`、最多 24000 步（1200 世界秒）、A/B/C/D × seed 0,1,2、
每次运行最多 8 个累计创建、神经网络为 BC（无奖励，不训练）。
数据：`experiments/results/ablation_final/runs.csv`、`aggregate.json`、`report.md`。

### 5.2 跨种子统计（均值 ± 标准差 [最小, 最大]）

| 指标 | A 原始 | B +规划 | C +知识传承 | D 完整 |
| --- | --- | --- | --- | --- |
| 累计创建 | 8.000±0.000 | 8.000±0.000 | 8.000±0.000 | 8.000±0.000 |
| 已验证技术 | 0 | 0 | **4.667±0.471 [4,5]** | **4.667±0.471 [4,5]** |
| 技术图深度 | 0 | 0 | 1.000±0.000 | 1.000±0.000 |
| 公共设施 | 0 | 0 | 4.000±0.000 | 4.000±0.000 |
| 创新有效率 | 0 | 0 | 0.411±0.055 | 0.411±0.055 |
| 目标完成率 | 0（无目标） | 0.937±0.007 | 0.987±0.005 | 0.986±0.007 |
| 最长连续同动作 | **4377.7±75.6** | **54.7±6.7** | 161.0±0.0 | 163.0±2.8 |
| 无进展重复比例 | 0.542±0.062 | 0.411±0.002 | 0.417±0.062 | 0.418±0.058 |
| 合作指数 | 0 | 0 | 0（社会机制关闭） | **0.867±0.094** |
| 灭绝时间(s) | **419.6±22.1** | **597.9±45.1** | **1031.3±1.1** | **1031.3±1.1** |
| 灭绝原因 | 8/8 饥饿 | 饥饿 | 老年（8 人封顶） | 老年（8 人封顶） |

### 5.3 逐项解释（不是只看均值）

- **A 组**：无规划/知识/传承。8 个名额约 150s 内用满，随后夜间食物短缺 → 全线崩溃
  （seed 0/1/2 分别在 430.95 / 388.65 / 439.10s 灭绝）。
  最长连续同动作 4377 步，说明个体在"没有目标"时确实退化为重复动作。
- **B 组**：仅加规划。目标层让个体持续采集/建造并规避饥饿，
  最长连续同动作 **4378→54.7 步**，灭绝时间 **+42%**。但仍无技术积累（tech=0）。
- **C 组**：加知识/传承。个体用合法动作采集材料 → 试验 → 模拟器验证 →
  建造设施 → 围绕设施定居 → 度过夜晚。跨 3 个 seed 分别验证 4/5/5 项技术，
  创新有效率 0.33–0.45，**全部因 8 人上限在老年期灭绝**（1030.05/1030.95/1032.80s）。
- **D 组**：加社会机制与扰动。灭绝时间与 C 相同（都触到 8 人×900s 的天花板），
  但出现可解释的社会差异：**合作指数 0.80–1.00（C 恒为 0）**；
  3 个 seed 分别经历 3 次环境扰动（如 seed0：drought@121.7s、scarcity@300.1s、
  storm@495.05s），行为熵略高（0.423 vs 0.416），合作收益指标不同（-0.642 vs -0.674）。

> **诚实结论**：在 8 人硬上限下，C→D 的寿命差异为 0（已触顶）；D 组新增机制的
> 可测价值在于**合作资源流（0.867）、扰动暴露与行为分布**，而不是"活得更久"。
> 我们不把"技术数量"当作文明水平的唯一证据：C/D 的技术数量相同，但 D 有真实的
> 合作与扰动响应。
>
> 另一个需要说明的饱和指标：`knowledge_retention` 在 A/B/C/D 全部为 1.000。
> 这不是"指标造假"，而是本实验条件的结果——已验证技术总共只有 4–7 条，
> 而教学 + 死亡档案让每条已验证技术始终至少被一个个体掌握或留在档案里，
> 因此"留存率"没有区分度。真正有区分度的是 `tech_verified`（0 vs 4.67）与
> `innovation_efficiency`（0 vs 0.41）。保留率要等到"知识总量 >> 个体容量"或
> "验证后长期无人使用"的场景才有意义，已在 §8 列为后续工作。

### 5.4 可解释的文明故事（D 组 seed0，逐条可追溯）

1. **为什么某项技术被发现**：个体在计划中先补采材料，再用 `experiment` 步骤
   向模拟器请求验证。`stone_axe` 在 0.95s 由 1 号个体首次发现并验证（当时的世界 RNG
   没有暴露缺陷），`fiber_cord` 0.45s、`campfire` 1.4s、`granary` 2.6s。
2. **如何被验证和传播**：验证走 `Technology.simulate_recipe`（真实扣 2 木 1 石等）；
   验证成功后写入发现者 `known_knowledge_ids`；170px 内邻居按概率学会，
   出生时子代继承父母已验证知识。存档显示：0 号掌握 4 项，1 号与其他成年个体 6 项。
3. **如何改变资源获取与后续技术**：石斧使单次采集 1→2；纤维绳解锁背篓/水井；
   粮仓在 240px 内持续供能，使 8 人群体越过浆果丛的自然承载力（夜晚不再饿死）。
4. **个体死亡后文明失去/保留什么**：死亡档案保留库存、掌握知识（如 1 号 6 项）、
   技能、亲子关系；活着的个体通过教学继续携带这些知识。
   亲代关系可查：1 号是 2/3/4/5/7 号的父/母，2 号又生下 6 号（第 2 代）。
5. **环境变化为什么影响路线**：风暴摧毁整丛浆果、资源枯竭清除整棵树/岩体、
   干旱让土壤湿度×0.35 并停止降雨；在 seed1 中首次风暴发生在 101.9s，
   与 seed0 的干旱 121.7s 造成不同的早期行为/目标序列（见 `runs.csv` 与事件 JSONL）。
6. **新增机制是否真的改善长期发展**：A→B→C 的灭绝时间 419.6 → 597.9 → 1031.3s
   是规划与知识的直接效果（目标完成率、重复动作、技术数、设施数同步变化）；
   C→D 的差异在合作与扰动响应，已在 §5.3 如实给出而不夸大。

1. **没有训练高层策略**：规划器是规则 + 代价搜索；神经网络仍是 BC（无奖励）。
   记忆/目标输入已接线，但 BC 教师数据中这些特征恒为 0，所以网络基本学不到
   "用记忆"，其价值主要由规划层承担。
2. **维护只在设施失效后触发**（无预防性维护）；`deliver` 是 contribute 别名；
   契约（SocialContract）只有数据结构，没有真正的协商/执行规则。
3. **合作机制只有食物分享**；没有交易、分工、声誉、惩罚。
4. **环境扰动只有 3 种一次性冲击**，没有气候趋势或长期资源再生曲线。
5. **C→D 寿命无差异**（8 人上限 + 食物技术已饱和），D 的收益体现在合作资源流与
   扰动响应，不能声称"让文明活得更久"。
6. GUI 的自动化测试缺失（无头环境限制）。

## 9. 风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 8 人上限使单次运行必然灭绝 | 约 1030s 后全灭 | 已作为设计事实写进 README/报告；指标聚焦积累与传承而非人口延续 |
