## P1：最小可训练环境（本次同批实施）

**假设 H1**：在固定地形与食物动态下，参数共享 IQL 策略的训练
回报曲线显著上升，且在训练外 seed 上平均寿命/进食效率
**配对击败**规则基线。

### 设计（详见代码）

* `newworld/swarm_policy.py`：`SwarmPolicy` 协议（act 批量接口）+
  `RuleSwarmPolicy`（现有梯度+wander 规则，原样抽出为基线）+
  `NeuralSwarmPolicy`（numpy MLP，9→32→5，softmax 采样）；
* `swarm.py`：行为决策段抽成 `policy.act(obs_batch)`；
  内置奖励（进食+1/死亡-10/时间-0.01·dt）与
  `(obs, action, reward)` 转移缓冲 + `drain_swarm_transitions()`；
  训练器复用 lowlevel_rl 的 minibatch/标准化/裁剪思想（独立轻量
  实现，因 dtype/动作空间不同）。

### 指标定义

| 指标 | 计算定义 |
|---|---|
| 累计奖励 | Σ 全体个体分步奖励 |
| 进食次数 | `food[y,x] -= bite` 成功次数 |
| 平均寿命 | Σ(age at death)/死亡数 |
| 90s 存活率 | t=90s 时 alive/N₀ |
| 进食效率 | 进食次数/(存活个体·秒) |
| 泛化 | 训练外 10 seed 的上述指标均值±std |

### 对照组（同地图/同 seed/同资源预算）

1. `random`：均匀随机 5 动作；
2. `rule`：RuleSwarmPolicy（V3 原行为）；
3. `untrained`：随机初始化的 NeuralSwarmPolicy；
4. `trained`：训练后的 NeuralSwarmPolicy。

**验收门槛**：trained 在 ≥8/10 训练外 seed 上，
进食效率或平均寿命配对优于 rule。达不到 → 报告差距与原因
（可能：9 维观测不足以定位食物 → P1.5 扩观测）。

### P1 执行结果（已运行，如实记录）

**P1 首轮**（12 回合训练 × 10 训练外 seed）：
- 寿命配对 10/10 胜 rule（当时判"门槛通过"），进食效率 6/10 不显著；
- 反直觉发现：random 进食量最高——**奖励歧义**（进食门槛 0.175
  让个体在残食格挨饿，站桩/游走的占位运气主导进食计数）。

**P1.5 修复**（吃残食 + 按量奖励 + 删除 rich_cell 自我抑制）后：
- 寿命仍 10/10 胜，进食效率 0/10；机制诊断：训练收敛到 90%
  单方向扫掠（真实可泛化行为，但在当时环境下次优）。

**P1.6 指标修复与假说证伪**（诚实修订）：
- `mean_life` 改为逐个体记录死亡年龄（`Swarm.death_ages`）后，
  **前两轮的"寿命优势"暴露为指标伪影**（无人死亡时 fallback 逻辑
  的 +30s 偏置恰好偏向 trained 组）；真实寿命差 -1.7±3.8（无差异）；
- 密度梯度（120/360/720 人）证伪"高密度下扫掠反超"假说——方向
  相反（Δ 从 -26 恶化到 -50），随机策略始终进食最多；
- **根因确诊：环境承载过剩**——食物再生速率约为总代谢消耗的
  10 倍，任何活法都饿不死（代谢 ×5 仍全员饱足）。没有觅食
  选择压力的环境里，"学习觅食"无从被优选。

**P1.7 稀缺环境**（食物再生 0.012 → 0.0005）——首个正结果：
- 站桩策略在稀缺下**饿死**（饱足 0.14、193 饿死、人口崩至 37），
  觅食移动成为生存必要——选择压力恢复；
- 稀缺环境重训后，trained 在 **5/5 快速 seed 上进食量配对胜
  rule（+19%～+42%）**，且稳定高于 untrained；动作分布均衡
  （四方向 11-27% + 原地 26%，不再单方向），符合"追踪食物梯度"；
- 完整 10-seid 结果见 `experiments/results/p1_baseline/report_p17_scarce.md`。

**P1 里程碑最终判定（P1.6 修订版）**：
- ✅ **机制闭环真实成立**——梯度经有限差分验证、配对对照可复现、
  动作分布可归因；
- ✅ **学习优势在稀缺环境成立**（P1.7，待 10-seed 确认）；
- ❌ 承载过剩环境中的"学习优势"声明**撤回**（P1/P1.5 两轮的正
  结果均被 P1.6 的指标修复与环境诊断推翻）。
- 方法学教训（写入实验纪律）：指标 fallback 逻辑会制造系统性
  偏置；"策略胜出"的前提是环境存在该策略的选择压力。

### 明确不学（P1 范围外）

进食执行/繁衍/死亡保持规则层——P1 只验证"去哪找食物"这一最
纯粹的决策问题。这是刻意的最小化（提案 §5.1）。

## P2：浏览器实验平台（下一批）

**假设 H2**：仿真内核与渲染解耦后，5000 个体 + 实时统计的交互
帧率 ≥30FPS（浏览器端）。

技术栈（用户已选）：FastAPI + WebSocket + PixiJS/React。

**接口契约（现在冻结，P2 实现）**：

```text
GET  /api/snapshot        只读世界快照（t/population/food/terrain digest/统计）
WS   /api/stream          增量帧流（个体位图/事件/指标，~20Hz）
POST /api/command         实验干预（pause/speed/seed/restart/catastrophe）
GET  /api/agent/{id}      个体详情（观测/动作历史/奖励）
GET  /api/experiments      实验列表与结果
```

铁律：渲染层只读快照；一切干预走 `/command` 并记录
（时间/参数/对象/原因）——人工操作成果不可归功于学习
（提案 §6.3）。

**验收**：点击个体显示详情；同 seed 前后两次 run 快照逐字段一致。

## P3：社会与文明机制（每机制独立开关+对照）

按 P1 结果排序，候选：

1. **交换**（Sugarscape 交易者规则）：真实转移 + 价格记录；
2. **知识传播**（复用旧世界 _social_learning 的 170px 半径 +
   概率，但目标是 P1 学到的觅食参数/技能）；
3. **继承**（复用 note_birth 模式）；
4. **技术**（knowledge 假设-验证状态机接 V3，RECIPE_CATALOG
   移入配置）。

**每个机制的验收**：开关该机制的配对 seed 对照（≥10 对）显示
目标宏观指标的因果差异（如交易开→财富基尼下降/分工出现），
否则该机制标记"已实现但证据不足"。
