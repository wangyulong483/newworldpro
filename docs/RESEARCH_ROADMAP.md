## P1：最小可训练环境（本次同批实施）

**假设 H1**：在固定地形与食物动态下，参数共享 IQL 策略的训练
回报曲线显著上升，且在训练外 seed 上平均寿命/进食效率
**配对击败**规则基线。

### 设计（详见代码）

* `newworld/swarm_policy.py`：`SwarmPolicy` 协议（act 批量接口）+
  `RuleSwarmPolicy`（现有梯度+wander 规则，原样抽出为基线）+
  `NeuralSwarmPolicy`（numpy MLP，9→32→5，softmax 采样）；
* `swarm.py`：行为决策段抽成 `policy.act(obs_batch)`；
  内置奖励（进食+1/死亡-10/时间-0.01·dt）与
  `(obs, action, reward)` 转移缓冲 + `drain_swarm_transitions()`；
  训练器复用 lowlevel_rl 的 minibatch/标准化/裁剪思想（独立轻量
  实现，因 dtype/动作空间不同）。

### 指标定义

| 指标 | 计算定义 |
|---|---|
| 累计奖励 | Σ 全体个体分步奖励 |
| 进食次数 | `food[y,x] -= bite` 成功次数 |
| 平均寿命 | Σ(age at death)/死亡数 |
| 90s 存活率 | t=90s 时 alive/N₀ |
| 进食效率 | 进食次数/(存活个体·秒) |
| 泛化 | 训练外 10 seed 的上述指标均值±std |

### 对照组（同地图/同 seed/同资源预算）

1. `random`：均匀随机 5 动作；
2. `rule`：RuleSwarmPolicy（V3 原行为）；
3. `untrained`：随机初始化的 NeuralSwarmPolicy；
4. `trained`：训练后的 NeuralSwarmPolicy。

**验收门槛**：trained 在 ≥8/10 训练外 seed 上，
进食效率或平均寿命配对优于 rule。达不到 → 报告差距与原因
（可能：9 维观测不足以定位食物 → P1.5 扩观测）。

### P1 执行结果（已运行，如实记录）

**P1 首轮**（12 回合训练 × 10 训练外 seed）：
- 寿命配对 10/10 胜 rule（当时判"门槛通过"），进食效率 6/10 不显著；
- 反直觉发现：random 进食量最高——**奖励歧义**（进食门槛 0.175
  让个体在残食格挨饿，站桩/游走的占位运气主导进食计数）。

**P1.5 修复**（吃残食 + 按量奖励 + 删除 rich_cell 自我抑制）后：
- 寿命仍 10/10 胜，进食效率 0/10；机制诊断：训练收敛到 90%
  单方向扫掠（真实可泛化行为，但在当时环境下次优）。

**P1.6 指标修复与假说证伪**（诚实修订）：
- `mean_life` 改为逐个体记录死亡年龄（`Swarm.death_ages`）后，
  **前两轮的"寿命优势"暴露为指标伪影**（无人死亡时 fallback 逻辑
  的 +30s 偏置恰好偏向 trained 组）；真实寿命差 -1.7±3.8（无差异）；
- 密度梯度（120/360/720 人）证伪"高密度下扫掠反超"假说——方向
  相反（Δ 从 -26 恶化到 -50），随机策略始终进食最多；
- **根因确诊：环境承载过剩**——食物再生速率约为总代谢消耗的
  10 倍，任何活法都饿不死（代谢 ×5 仍全员饱足）。没有觅食
  选择压力的环境里，"学习觅食"无从被优选。

**P1.7 稀缺环境**（食物再生 0.012 → 0.0005）——首个正结果：
- 站桩策略在稀缺下**饿死**（饱足 0.14、193 饿死、人口崩至 37），
  觅食移动成为生存必要——选择压力恢复；
- 稀缺环境重训后，trained 在 **5/5 快速 seed 上进食量配对胜
  rule（+19%～+42%）**，且稳定高于 untrained；动作分布均衡
  （四方向 11-27% + 原地 26%，不再单方向），符合"追踪食物梯度"；
- 完整 10-seid 结果见 `experiments/results/p1_baseline/report_p17_scarce.md`。

**P1 里程碑最终判定（P1.6 修订版）**：
- ✅ **机制闭环真实成立**——梯度经有限差分验证、配对对照可复现、
  动作分布可归因；
- ✅ **学习优势在稀缺环境成立**（P1.7，待 10-seed 确认）；
- ❌ 承载过剩环境中的"学习优势"声明**撤回**（P1/P1.5 两轮的正
  结果均被 P1.6 的指标修复与环境诊断推翻）。
- 方法学教训（写入实验纪律）：指标 fallback 逻辑会制造系统性
  偏置；"策略胜出"的前提是环境存在该策略的选择压力。

**P1 复核（P5 轮，配置化协议重跑）——P1.7 正结果撤回**：

P1 迁入 `configs/p1_scarce.yaml` 后，在训练/评估 seed 不相交且加入
random/untrained 开环基线的条件下重跑（10 回合训练，6 个训练外
seed × 90s）：trained 对 rule 的 eat_rate 6/6 胜（Δ=+0.522），但
**不学习的 random（+0.472）与 untrained（+0.502）同样 6/6 胜 rule，
trained vs random/untrained 只有 3/6**；trained 的 satiation
（0.782）与 mean_life（55.1s）都差于 rule（0.970 / 79.3s）。
机制：eat_rate 是"进食事件次数"，rule 吃饱后休息导致事件少，
移动策略持续小口吃导致事件多——这是事件计数伪影，不是学习优势。

→ **P1.7 的"学习觅食优势"撤回**；保留模型作为负结果证据，不再作为
"学习有效"的依据。这是本项目第二次自我纠错（第一次是 P1.6 的
mean_life 伪影），也是 P5 工程化（统一 config + 开环基线）带来的
直接收益。

## P4 执行结果（已运行，如实记录）

三臂配对对照（rule / evolution / learning × 5 eval seeds，稀缺世界，
120s 评估；evolution = 技能分布 θ 演化 4 代，learning = 策略梯度
8 回合独立训练——OpenAI ES 理论依据见 REFERENCES 第二轮调研）：

| 臂 | 进食效率 vs rule（配对） | 结论 |
|---|---|---|
| evolution（技能分布变异+选择） | 1/5 胜，Δ=-262±261 | **无效应** |
| learning（NeuralSwarmPolicy REINFORCE） | **5/5 胜，Δ=+6368±3896** | 显著正效应 |

**机制定性（诚实记录两个根本原因）**：

1. **演化臂的表型太弱**：P3 技能中只有 slow_metabolism 在残食
   环境有真实生理优势（bite 被 available≤0.008 的残食上限截断、
   move 的 3 格探测半径有限）。θ 演化能在三个弱表型间重新分配，
   但弱表型的组合怎么分配也超过不了无技能基线多少。
2. **信号通道对比悬殊**：learning 每步获得连续稠密的
   `(obs, reward)` 梯度信号（每回合 ~20 万条转移）；evolution 每
   60s 一代、只有"整代存活饱足均值"一个标量。这是 ES vs PG 的
   结构性差距在本环境的具体体现——**离散弱表型 + 短程评估下，
   学习通道信息量高出演化通道三个数量级**。

这与理论预期一致（OpenAI ES 需要海量并行 rollout 补偿信号稀疏——
我们的演化臂每代只跑 1 个 rollout）。不是说演化无效，是当前
实现规模下无效应——θ_final 分布显示演化确实在动（偏好 efficient_biter
0.33-0.45，它有三技能中最强的代谢保护），只是表型增益 < 噪声。

**技能接线（P4 另一半工作）**：bite/move/metabolism 三钩子已接
入 swarm 行为层（`swarm.skill_effect`，依赖倒置设计），断粮存活
测试证明 slow_metabolism ×0.75 端到端生效（存活时间 +>10%，
test_metabolism_skill_improves_survival 锁定）。

**P4 复核（P5 轮，配置化协议重跑）——"learning 显著正效应"降级**：

旧 P4 的 learning 臂存在**同 seed 训练泄漏**（训练/评估用了同一批
seed），且只看 eat_events。重跑修正为训练 seed [500,501] 与评估
seed [1100-1104] 不相交后：learning 臂 eat_events 4/5 胜
（Δ=+6077，+45%），但 **satiation Δ=-0.260（0/5）、mean_life
Δ=-20.8s（0/5）、population Δ=-47.6（0/5）——三项适应度指标全
更差**。与 P1 复核同因：eat_events 是可被"频繁小口吃"刷高的计数。
→ 旧 P4 的"学习显著正效应"降级为**事件计数增加，不是适应度增益**；
演化臂仍无效应（1/5，Δ=-180±210）。

**灾害/上帝之手已彻底移除**（抽象模拟≠上帝模拟器；P5 清理轮）：
`catastrophes.py` 模块、meteor/lightning/flood/heal 接口、lab 的
catastrophe 命令、GUI/前端的施放工具栏全部删除；`MapEngine` 不再
有 `ignite/burning/burn_left/cells_burned/set_terrain` 等写地图
入口，群伙也没有"火中死亡"。世界动态只来自规则（食物再生、森林
蔓延、代谢、繁衍、社会机制）；人工干预仅保留
pause/speed/step/reset 四项实验控制并全部入审计。
`tests/test_map_world.py` 用负向测试锁定这些能力不存在。

## P6：涌现通信与生成式记忆（去 LLM）（本轮交付 ✅）

### P6-A 涌现通信通道

**设计**：群伙新增离散信号通道（K 个符号、半径内广播）。发送者
策略与移动策略分离：发送者用**群体奖励**（每步人均进食增量）训练，
接收者的观测追加"听到的符号直方图"（K 维 provider），移动策略用
个体进食奖励训练。语义不硬编码——没有任何"食物在东边→符号 2"
的规则；语义是否形成由互信息/对齐率测量。

**两条证据链**：

1. **受控指称博弈**（Lazaridou 式）：发送者看 4 选 1 的隐藏线索、
   发 1/4 符号；听者只看符号、必须选对线索；两者共享 0/1 奖励。
   测量准确率 vs 随机 25%、符号-线索互信息（bits）、符号熵和
   cue→symbol 映射。这是"协议能否形成"的干净证据。
2. **世界内通道消融**：同 seed 配对，channel off vs on，各训练同样
   回合后评估进食/饱足；on 组报告通道统计（互信息/熵/对齐率）。
   预期个体奖励 + 参数共享下通道未必有用——**负结果如实报告**。

**验收**：指称博弈准确率显著高于 chance 且 MI>0；世界消融给出
点估计与配对胜负，不宣称显著。

### P6-B 生成式记忆与反思（无 LLM）

**设计**（Generative Agents 的非 LLM 机制层）：

* **记忆流**：每个体的结构化事件（吃到食物/濒死/休息/反思），
  字段 = 时间、类型、标签、重要性、特征向量；
* **检索**：`score = w_r·2^(-Δt/half-life) + w_i·importance +
  w_v·cos(feature, query)`，取 top-k；
* **反思**：每 N 秒把新事件聚合成更高层"洞见"（主导食物方向 /
  风险占比），以高重要性写回记忆流；
* **特征**：检索结果 → 6 维观测 provider（记忆食物方向、成功率、
  风险率、反思偏置），接入移动策略。

**验收**：配对 seed 消融 off / recency-only / full / full+reflection；
报告进食、饱足、存活与记忆统计的效应量；**无效应就如实写无效应**
（P4 的教训：弱表型 + 短程评估下不要过度解读）。

## P5 执行结果（已运行，如实记录）

完整数据与图见 `docs/EXPERIMENTS.md` §P5；本文件只留判决。

* **Sweep A（人口→吞吐）**：N=60→960 时吞吐 1000.6→424.1 steps/s；
  幂律 b = **-0.302**，R²(log) = **0.926**，n=5。结论：吞吐随人口
  **亚线性**下降（固定每步开销 + 随人口增长的个体成本），是实现
  wall-clock 描述，不是理论复杂度结论；两次运行的 b=-0.302/-0.317
  说明机器负载敏感。
* **Sweep B（算力→学习表现）**：episodes 1/2/4/8/16 的 eat_events
  5949→6009（峰值在 8），b = **+0.0078**，R² = **0.227**，n=5。
