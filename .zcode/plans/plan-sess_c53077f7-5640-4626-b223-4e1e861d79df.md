# P0+P1：从上帝模拟器到人工生命研究平台

## 审查结论（基于代码证据，非模块名）

### 诊断一：两个世界都没有真正的"可训练智能体"

- **V3 新世界（当前默认）**：`swarm.py` 的个体只有 7 个数值字段（x/y/hunger/age/breed_cd/tribe/alive），全部行为是硬编码数值规则+随机抽样（进食 swarm.py:252、移动梯度+wander swarm.py:265-306、繁衍概率抽样 swarm.py:311-322）。**无策略接口、无转移记录、无奖励**——BC/RL 全部悬空在旧世界，这正是提案说的"没有独立决策能力的粒子"。
- **旧世界**：学习链路真实存在（lowlevel_rl 训练器+rewards+minibatch 修复已提交，信号增强 100-210 倍），但**高层学习策略只控制 0.7% 的决策帧**（goal_policy_ablation.json 实测：teacher 63.3%、neural 34.2%、policy_goal 0.36%），且整个决策链服务的是 8 人小世界。

### 诊断二：关键资产清单

| 档 | 资产 |
|---|---|
| 直接复用 | telemetry（19 指标、世界无关）、RunSpec/SocietyRunner/JSONL、lowlevel_rl 训练器（minibatch/优势标准化/裁剪全套）、rewards 反刷分设计、knowledge 假设-验证状态机、Catastrophes 圆形区域干预、ui_state.Viewport、MapEngine 确定性地形、Swarm 向量化骨架 |
| 小改复用 | Swarm（行为段抽成可注入策略）、RECIPE_CATALOG（移入配置）、MapRenderer（diff 渲染） |
| 退役候选 | app_map 全量重建路径、probe_* 旧脚本 |

### 诊断三：实验方法学缺陷（回应 §2.3）

V2 报告的"学习策略无文明级收益"结论，源于三点结构性原因而非训练不足：(a) 高层策略触发面窄（只在无目标时被询问）；(b) 奖励以文明级 Δ 计，个体动作与奖励间隔太远（信用分配跨度=分钟）；(c) 对照组里规则教师控制 63% 决策，学习策略的被测面太小。**P1 的奖励设计直接吸取此教训：个体级、短周期（秒级）、稀疏事件奖励。**

## 调研结论（要点，全文将写入 RESEARCH_REFERENCES.md）

- **ALife（Avida/Tierra）**：不引入代码（C++/LGPL、基因组=可执行码范式不匹配），借鉴变异算子、能量配额选择压力、多样性指标；
- **人工社会（Sugarscape/Axelrod/Mesa）**：采用 Mesa DataCollector 接口约定 + Sugarscape 现象学基线（财富分化/迁徙波）；不整体迁移 Mesa 框架；
- **MARL**：CTDE/QMIX/MAPPO 在纯 numpy 千级场景不可行（勘误：MAPPO 正确编号 arXiv:2103.01955，QMIX arXiv:1803.11485）；**参数共享 IQL 是唯一现实落点**，PettingZoo AEC 接口标准（生灭生命周期一等公民）；
- **UI**：自建 FastAPI+WebSocket+PixiJS/React 主线（用户已选）；Godot 因 Python 集成硬伤排除。

## P1 设计：改造 V3 地图为最小可训练环境（用户已选）

### 1. 策略接口（Swarm 改造，~1 天）

把 `Swarm.update` 的移动/进食决策抽成可注入策略：

```python
class SwarmPolicy(Protocol):
    def act(self, obs_batch: np.ndarray) -> np.ndarray  # (N, action_dim)

class RuleSwarmPolicy:   # 现有梯度+wander 规则，作为基线
class NeuralSwarmPolicy: # numpy MLP，参数共享 IQL
```

观测（个体级、有限视野，仿 PettingZoo 部分可观测）：9 维——自身 hunger/age、所在格食物、4 方向视野食物、随机数种子性个体噪声。动作：4 离散移动方向 + 原地（食/繁衍保持规则层，P1 不学习——先验证最纯粹的"觅食学习"）。

### 2. 奖励与转移（~1 天）

- 个体级奖励：进食 +1、死亡 -10、每步 -0.01 时间成本（秒级信用分配，吸取 V2 教训）；
- 转移记录：Swarm 内置 `(obs, action, reward)` 批量缓冲，drain 接口仿 population.drain_lowlevel_transitions；
- 训练循环：复用 `LowLevelTrainer` 的 minibatch/标准化/裁剪（改 dtype 适配）。

### 3. 基线对照实验（P1 验收核心，~1 天）

同一地图（MapEngine 不动）、同 seed、配对对照四组：随机策略 / 现有规则策略 / 训练前网络 / 训练后网络。指标（每项有计算定义）：累计奖励、进食次数、平均寿命、存活率、种群增长曲线、未见 seed 泛化。**验收门槛：训练后网络在 ≥8/10 训练外 seed 上击败规则基线的平均寿命或进食效率**——达不到就如实报告差距。

### 4. P2 预告（本计划不实施）

浏览器平台（FastAPI+PixiJS）的接口契约在 P0 文档中定义：`GET /snapshot`（只读快照）、`WS /stream`（增量帧）、`POST /command`（实验干预，全部记录时间戳/参数/原因）。
