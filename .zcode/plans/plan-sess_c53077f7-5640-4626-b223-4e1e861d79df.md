# 世界盒子式重构计划（两期）

## 总体架构决策

按你的选择：**彻底替换**侧视世界、**纯数据粒子**千人引擎、**分两期**落地。核心思路是不在旧 World 上打补丁，而是新建一个以俯视地图 + cell 人口为中心的 `WorldMap` 世界，旧的 per-agent 神经/感知/精灵体系整体退役。

```
newworld/
├── map_engine.py    ← 新核心：俯视地形网格（复用 materials 注册表 + infinite_scene 的分块哈希）
├── swarm.py         ← 千人群伙：numpy 结构化数组（位置/饥饿/年龄/族群id），批量更新
├── tribes.py        ← 二期：部落形成、边界、战争、同化
├── catastrophes.py  ← 一期末尾：圆形区域灾害（火山/陨石/洪水）+ 上帝之手
├── map_render.py    ← 俯视地图渲染（grid→色块 PIL 图，agent→2px 点）
├── app_map.py       ← 新 GUI：复用现有 Viewport/面板框架，替换世界渲染与选择逻辑
└── simulation.py    ← RunSpec 扩展 world_mode="map"，SocietyRunner 分流
```

## 复用清单（侦察结论）

| 复用 | 资产 |
|---|---|
| 直接 | `materials.py` 材料注册表（uint8 网格天然是俯视 cell 编码）、`ui_state.py` Viewport 缩放平移、`telemetry.py` 全部指标采集（鸭子类型无世界假设）、`simulation.py` 实验框架、`daynight.py` 时间系统 |
| 小改 | `infinite_scene.py` 的 splitmix64/chunk/全局修改持久化（重写为 2D 布局）、`ecology.py` 湿度扩散与降雨（去掉 surface 行概念）、`app_tk.py` 控制/列表/详情/日志面板 |
| 退役 | 侧视 ground_y 体系（29 处引用整体拔除）、per-agent 神经网络/感知栈（retina/optics/perception）、精灵渲染、单人文明层（goals/knowledge/civilization 部分保留思路） |

## 第一期（本次执行）

**1. `map_engine.py` — 俯视地形**
- `MapEngine`：`terrain` uint8 网格（深水/浅水/沙滩/草地/森林/山地/雪），由 seed 确定性生成（值噪声 → 温度/海拔阈值分层）
- `food` float 网格：草地/森林上按光照+湿度再生长，被种群吃掉
- 复用 `materials.py` 注册表风格；保留 InfiniteScene 的 chunk 思想做**大地图**（如 512×320 cell，非无限）

**2. `swarm.py` — 千人群伙**
- numpy 结构化数组：`x, y, hunger, age, tribe_id, alive`（千人 = 6×1000 数字）
- 每帧批量更新（向量化）：饥饿增长→进食（查 food 网格）→移动（向食物梯度 + 扩散噪声）→繁衍（饱足+成年+人口上限按食物容量）→死亡（饥饿/老龄）
- 初始人口 ~200，上限按食物总量的动态承载力（预计自然增长到 800-2000）

**3. `map_render.py` + `app_map.py` — 俯视 GUI**
- 渲染：terrain→固定色块 PIL 底图（增量更新：只重画变化的 cell），agent→按 tribe 着色的 2px 点（Canvas 批量矩形）
- 复用：Viewport 缩放/平移/滚轮、控制栏（开始/暂停/单步/速度/重置）、右侧智能体列表（改为按部落聚合：部落名/人口/平均状态/领土）、详情面板（点选部落）、事件日志
- 底部状态栏：总人口/出生死亡速率/食物总量/帧率

**4. 灾害 + 上帝之手（一期末）**
- `catastrophes.py`：圆形区域灾害——陨石（点火+坑洞：cell 变焦土）、闪电（引发森林火灾：燃烧扩散）、洪水（低地淹水）
- 上帝之手：GUI 工具栏选中"陨石/闪电/洪水/治愈"，点击地图施放（同时给 WorldBox 式的爽感与扰动实验入口）

**5. 旧世界退役**
- CLI 默认启动新世界：`python -m newworld` / start_world.bat → 俯视地图模式
- 侧视世界入口移到 `--classic`（代码保留一个版本供怀念，不进测试主线）
- Population/decision 链对新世界不走（无 per-agent NN）
- 旧测试（525 个）按模块退役：与侧视强绑的 test_vision/test_body/test_perception 等标记 skip-classic；新世界测试新建 `tests/test_map_engine.py`、`tests/test_swarm.py`、`tests/test_catastrophes.py`

**验收标准（第一期）**
- 512×320 地图上 ≥1000 个体 60 FPS 滚动（tkinter 渲染增量）
- 人口自然繁衍到动态承载力并随灾害波动
- 点选部落看详情、三种灾害可施放且效果真实（食物网格/人口真实变化）
- 新增测试 ≥40 个，全套回归绿

## 第二期（后续）

- **部落/国家**：tribe_id 从亲缘聚簇涌现 → 领土 cell 归属（染色）→ 边界冲突/战争/同化/移民
- **神迹扩展**：瘟疫、地形笔刷（造山/挖湖/种林）
- **地图编辑**：暂停时拖拽绘制地形
- 实验：文明兴衰周期统计（工具框架复用 RunSpec/telemetry）

## 关键取舍

- **不迁移** per-agent 神经策略/视觉感知——千人规模下放弃"个体智能"，智能涌现自规则+统计，这正是世界盒子的精髓
- **保留** civilization 层的**思想**（知识/技术/设施作为 tribe 级属性而非个体属性），二期实现
- 生态简化为一层 food 网格（不再模拟单株植物原子）
- telemetry/实验框架全保留——新世界一样可做严肃实验
